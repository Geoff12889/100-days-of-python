This repository documents my progress through *100 Days of Code: The Complete Python Pro Bootcamp* by Dr. Angela Yu on [Udemy](https://www.udemy.com/course/100-days-of-code/).

The goal of this challenge is to build consistency as a developer by coding every day while learning Python through hands-on projects, exercises, and real-world applications.

## About

Over 100 days, I’ll build Python projects ranging from beginner exercises to automation tools, API integrations, data projects, and web applications.

## Why I'm Doing This

As I transition into software development, I want to build strong programming fundamentals through consistent daily practice and project-based learning.
